# 经济循环与资源层：需求驱动的增长螺旋

- Status: implemented（E1–E5 已实现，World v5）
- Depends on: ADR 0001（月度会议）、ADR 0002（自由数值）、ADR 0003（引擎/LLM 边界）、ADR 0004（修正叠算）、ADR 0005（不做兼容）
- Scope: 用支出法 C+I+G+NX 重建月度经济，加入 Stone-Geary 需求、劳动/利润分配、自动私人投资与国家资源禀赋。贸易、外交危机、战争目标另出计划。

### 0.1 已定约束参数

- 规模边际递减：`capacity ∝ count^0.98`（3000 座约 −3.7%，100 座约 −9%）。
- 资本门槛：基础 4%/年 + 债务率 × 2%；预期回报低于门槛的利润转闲置。
- 劳动力：`laborDemand = farms×0.3 + mines×0.6 + factories×1.0 + railroads×0.2 + ports×0.4 + offices×0.1 + universities×0.2 + barracks×0.3`（万）；`laborForce = peasants×0.6 + workers + artisans`；利用率夹在 0.5–1。
- 价格平滑：沿用 0.3 的月度收敛系数。
- 政府需求：按 §2.3 的支出映射表，把支出金额转为对应商品需求。

### 0.2 实施记录：基线校准与口径偏差

E1–E5 实现后，用 60 个月无决策基线跑出了第一版数值，随后做了以下**显式记录**的调整
（用户已授权「基线后可调并记录」）。这些不是静默改参数：

| 项 | 原定 | 实际 | 理由 |
| --- | --- | --- | --- |
| GDP 估值 | 按成交价 | 按基期价（实际 GDP） | 新产能压低消费品价格时，名义 GDP 会倒退；实际 GDP 才能表达增长 |
| 生存底线 | 表中原值 | ×0.6（`SUBSISTENCE_SCALE`） | 原值 693 金/月高于开局各国的收入，经济被锁在生存陷阱；缩放后开局有可用的超额收入 |
| 消费倾向 | 弹性份额和为 1，超额收入全花掉 | 超额收入 ×0.75（`CONSUMPTION_PROPENSITY`） | 全额消费使支出乘数达到 ~13，投资冲击会放大成失控增长 |
| 税基系数 | 未定 | GDP × 税率 × 0.45 | 使开局财政大致平衡；RUS/OTT 仍会因军费出现赤字，由 AI 决策处理 |
| 家政手工业 | 只计建筑产出 | 手工业者提供成衣/酒/家具/服务的基础产出 |  agrarian 国家否则会永久短缺，民怨失控 |
| 失业 | 直接取目标值 | 每月向目标平滑 25%（单月最多 ±1.5 点），并加 `(1−利用率)×2` | 避免开局一个月从 6% 跳到 30% |
| 私人投资闲置 | 按 `idleRetained` 留存 | 超过「活跃私人项目月成本 ×3 + 10」的部分按比例释放 | 否则私人资本无限累积，投资循环停摆 |
| 劳动份额修正 | 未定 | `laborShare` 修正入口按 fraction 处理 | percent 修正直接乘在 0.35–0.70 的份额上 |

结果：60 个月基线中大清 GDP 从约 533 增长到约 972（约 1.8 倍，年均 ~12%），
失业先升后降、激进不失控；普鲁士与日本在同政策下煤铁产量因禀赋差异分化。
测试见 `tests/economic-loop.test.ts`。

## 1. 月度结算顺序

1. 读取资源禀赋，计算每种商品的资源乘数。
2. 计算产能与产出（建筑 × 科技 × 交通 × 市场接入 × 资源乘数）。
3. 汇总需求四块：消费 C、投资 I、政府 G、净出口 NX（本切片为 0）。
4. 价格与短缺：需求/供给比平滑调价；短缺抑制消费、推高利润，过剩压低价格。
5. 计算 GDP = C + I + G + NX（按成交价）。
6. 收入分配：劳动份额 → 工资；其余 → 利润；税收与转移支付。
7. 私人储蓄与投资：利润 × 储蓄率 → 私人资本池；按利润/缺口分配项目。
8. 建造队列：国有项目用国库，私人项目用私人资本；官僚效能决定进度。
9. 政府预算：税收 + 关税（贸易接入前为 0）− 支出；赤字进债务。
10. 人口、生活水平、激进、合法性、官僚、阈值修正与科技。
11. 到期修正与状态阈值。

## 2. 需求

### 2.1 消费（Stone-Geary）

每个商品有每人生存底线 `subsistence[good]` 与收入弹性 `elasticity[good]`（弹性和为 1）：

```
 subsistenceCost = Σ subsistence[g] × price[g]
 supernumerary   = max(0, incomePerCapita − subsistenceCost)
 demand[g]       = population × (subsistence[g] + elasticity[g] × supernumerary / price[g])
```

- 劳动收入主要购买必需品（粮食、成衣、家具、酒、服务）。
- 资本利润的消费部分主要购买奢侈品、家具、服务（收入弹性更高）。
- 需求随收入增长但逐步饱和，避免无限螺旋。

已定参数（每 popFactor = 人口万 / 1000，每月）：

| 商品 | 生存底线 | 收入弹性份额 |
| --- | --- | --- |
| 粮食 | 7.0 | 0.15 |
| 成衣 | 1.2 | 0.18 |
| 家具 | 0.3 | 0.10 |
| 酒类 | 0.6 | 0.10 |
| 服务 | 1.0 | 0.27 |
| 奢侈品 | 0.02 | 0.20 |

清国 popFactor≈40 时生存成本约 693 金/月；粮食需求约 370，与旧手感接近。奢侈品弹性最高，粮食最低，收入上升自然升级消费。

### 2.2 投资需求 I

建造队列中的每个项目按月产生投资品需求（木材、钢铁、机械、家具），私人项目与国有项目都计入。

### 2.3 政府需求 G

支出类别映射到商品：

| 支出 | 主要商品 |
| --- | --- |
| 陆军/海军 | 军械、机械 |
| 官僚/教育 | 服务、家具 |
| 福利 | 粮食、成衣 |
| 建设 | 木材、钢铁、机械 |

实现时福利改为纯转移支付（进入家庭消费预算 C），建设改为按实付计入 I；两者都不再作为政府购买 G，避免重复计算（见 §0.4）。

### 2.4 净出口 NX

本切片固定为 0；双边贸易计划接入后替换为实际出口减进口。

## 3. 收入分配

```
 unemployment = 现有公式
 laborShare   = clamp(profile.laborShareBase − (unemployment − 5) × 0.01, 0.35, 0.70)
 wages        = GDP × laborShare
 profits      = GDP × (1 − laborShare)
 savingsRate  = profile.savingsRate × (1 + privateInvestment/100)
```

每国在 `COUNTRY_SEEDS` 中显式配置 `politicalEconomy`：

| 国家 | 劳动份额 | 储蓄率 | 闲置留存 | 投资信心 |
| --- | --- | --- | --- | --- |
| 英国 | 0.52 | 0.42 | 0.55 | +10 |
| 法国 | 0.55 | 0.35 | 0.50 | +5 |
| 普鲁士 | 0.54 | 0.38 | 0.55 | +8 |
| 美国 | 0.54 | 0.40 | 0.55 | +12 |
| 大清 | 0.62 | 0.20 | 0.40 | −5 |
| 俄国 | 0.63 | 0.18 | 0.35 | −8 |
| 奥地利 | 0.60 | 0.22 | 0.40 | −3 |
| 日本 | 0.60 | 0.24 | 0.45 | 0 |
| 奥斯曼 | 0.62 | 0.18 | 0.35 | −6 |
| 西班牙 | 0.61 | 0.20 | 0.40 | −4 |

- 工资进入劳动家庭消费预算；利润按各国储蓄率分为投资与资本家消费。
- 闲置留存是该国闲置利润留在私人资本池的比例，其余转为奢侈品消费。
- AI 投资信心与政策修正叠加在 `profile.investmentConfidence` 之上。
- 税收从工资/利润中扣除；福利作为转移支付回到劳动家庭。
- 阶级人口权重影响两组的消费规模；本切片先用总量 × 份额。

## 4. 私人投资

```
 savings       = profits × savingsRate × (1 + privateInvestment/100)
 privateCapital += savings
 投资分配：按未满足需求（demand / production）排序，并乘以资源/工业潜力；
 资本门槛为 4%/年 + 债务率 × 2%，信心政策会降低门槛
 项目进入建造队列（owner='private'），每月从 privateCapital 支付
 闲置资金：按 profile.idleRetained 留存私人资本，其余转为奢侈品消费（受政策与信心修正）
```

- 私人项目在 UI 中可见，标注「私人」，**不可取消**。
- 私人项目不花国库；官僚效能与建造容量同样限制进度。
- AI 每月可在信封内调整投资信心；玩家用政策/天命影响。

新增修正入口：`privateInvestment`（储蓄/投资比例）、`laborShare`（分配）、`consumption`（消费倾向）。

## 5. 资源层

```ts

// 新增资源只改这张表

```

- 每国 `resources: Record<ResourceId, number>`（0–100）。
- `resourceFactor = (endowment − 50) / 50 × 0.3` → 单资源 −0.3..+0.3。

- 不枯竭；勘探/发现/枯竭事件留到后续资源切片。
- 贸易接入后，`可用资源 = 本国禀赋 + 进口原料`；战争/禁运会削减进口项。

## 6. AI 月度批量

- 每月一次 `model.complete`，覆盖所有 AI 国家。
- 每个国家的决策新增：经济参数（税率/关税/支出）、建造、投资信心、外交动作。
- 玩家国家不进入批量；由主模型/秘书通过工具决策。
- 模型超时或返回无效 → 确定性政策兜底。
- 输出 token 预算继续放宽（当前 2400，实施时可上调到 3000）。

## 9. 测试

1. **60 个月基线**：所有数值有限，GDP 温和增长，无失控。
2. **需求冲击**：12 个月消费政策 → 利润上升 → 私人投资与产能上升 → GDP 与需求上升；冲击结束后回落并稳定。
3. **资源差异**：普鲁士（煤铁高）与日本（煤铁低）在同一政策下工业增长显著不同。
4. **劳动力约束**：低人口高投资 → 失业下降、劳动份额上升、增长放缓。
5. **需求饱和**：收入翻倍时粮食需求不翻倍，奢侈品需求明显上升。
6. **私人投资**：不扣国库、进入队列、不可取消；闲置利润按比例转换。
7. **确定性**：同种子同决策 60 个月后 GDP 等数值一致。
8. **渲染**：经济页在 terminal/desktop 可绘制。
