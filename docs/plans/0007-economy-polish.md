# 经济系统打磨（Economy Polish）

- Status: proposed（当前最高优先级；0002 事件树与多国交互暂停）
- Depends on: `0003-economic-loop.md`、`0004-trade-diplomacy.md`、ADR 0006（净资产财政）、`0006-gm-engine-interface.md`
- Scope: 不推翻现有结构，先让 1836 起局的贸易、财政、建造、科技与劳动力在 24 个月内**可解释、可操作**。事件/多国交互暂缓。

## 0. 试玩诊断（1836.01–02，大清）

| 现象 | 数据 | 判断 |
| --- | --- | --- |
| 全球粮食过剩 | 10 国全部是 offer，0 个 bid | 农产品没有世界市场，出口战略失效 |
| 成衣/酒/家具/军械同样过剩 | 各国全部 offer | 消费品贸易只剩布料与奢侈品 |
| 真正有 bid 的商品 | 煤（清 −35、法 −2）、铁（清/英/法）、布（清/日）、机械（全体）、奢侈品/鸦片（清） | 贸易只发生在“工业缺口”上 |
| 大清出口 | 0 金 | 粮食/木材/成衣都卖不出去 |
| 大清进口 | 16 金（煤 7.9、布 4.7、奢侈品 1.4、鸦片 1.2、铁 0.8） | 全部是必需品 + 少量非必需 |
| 贸易缺口 | 16 金，支付能力 ≈ 私人资本 + GDP×3% ≈ 15 金 | 缺口全部转外债，净资产 13→0 |
| 建造队列 | 按 `monthsLeft` 排序，矿场 65%、官署 52%、铁路 0% | 长工期项目被永久饿死；现金约束不透明 |
| GDP | 首月 I = 0，尽管已付建设款 | 投资口径有一个月滞后，账本难解释 |
| 科技 | 4 所大学约 2.2 点/月，1→2 要 140 点 | 升级需约 64 个月，节奏过慢 |
| 劳动力 | 原始利用率 3.8%，失业 7.5% | 两个口径打架，玩家无法判断 |

## 1. 目标与非目标

**目标**
- 任意一个月都能用账本解释：收入、支出、贸易缺口、净资产变化各是多少，为什么。
- 贸易存在分工：至少农产品有双向流；大清能靠出口或进口替代维持支付能力。
- 建造队列可预期：每个项目有明确的月拨款、进度与预计完工月，不出现永久 0%。
- 科技与劳动力有节奏：4 所大学时 1→2 不超过 24 个月；失业指标与利用率口径一致。

**非目标（本期不做）**
- 多国交互事件树、局势/仲裁扩展（0002 暂停）。
- 科技树 v8（0005 等 E5 校准后再做）。
- 新增商品、新战争目标、新外交动作。

## 2. 工作包

### E1 世界贸易校准（P0）

- **诊断测试**：跑 24 个月，逐商品统计全球 bid/offer；断言每种商品每年至少出现一次 bid 和一次 offer；大清至少有一个月出口 > 0。
- 可选手段（成本从低到高）：
  1. 调国家种子：减少各国农场数、提高城市人口与消费需求；
  2. 调农场产出 / 粮食需求参数；
  3. 引入“世界其余地区”外部需求（按价格弹性吸收过剩农产品）；
  4. 让 AI 国家按比较优势专业化（少种粮、多建工厂）。
- **目标指标**：粮食全球 bid/offer 比 > 0.2；大清第 12 月出口收入 ≥ 5 金/月。

### E2 贸易与支付能力可见化（P0，依赖 0006）

- `v3_inspect trade`：双边流、进口账单、出口收入、关税、支付能力分解（出口 + 私人资本 + GDP×3%）、贸易缺口。
- `v3_forecast`：下月预测，并标注瓶颈是现金、建设预算还是支付能力。
- HUD / AbovePrompt 显示贸易缺口与支付能力，推进前给出警告。
- **验收**：玩家不读存档即可解释上月净资产变化。

### E3 建造队列公平与可见（P1）

- 现状：按 `monthsLeft` 排序，长工期项目（铁路）长期拿不到钱。
- 备选方案：
  - A. 按入队顺序（玩家优先级）；
  - B. 按 `monthlyCost` 比例分配预算；
  - C. 每项保留最低拨款，余额按比例分配。
- 状态与面板显示：本月预计拨款、进度、预计完工月、是否因现金暂停。
- **测试**：现金紧张时每项要么有非零进度，要么明确标记“暂停”，不允许静默饿死。

### E4 GDP 与账本一致性（P1）

- 确认当月建设支出进入 I；私人建设与国有建设分开显示；C+I+G+NX 必须等于 GDP。
- 若保留一个月滞后，状态里明确写“本月 I 来自上月建设拨款”。
- **测试**：I 与建设支出同阶；GDP 分量求和等于 GDP。

### E5 科技与劳动力节奏（P1）

- 科技：目标“4 所大学时 1→2 ≤ 24 个月”；调整基础点数或科技成本。
- 劳动力：统一 `unemployment` 与 `laborRawUtilization` 口径；城市化 pull 提到可感知量级。
- **测试**：24 个月至少升 1 级科技；工厂数增加时失业率下降。

## 3. 实施顺序
