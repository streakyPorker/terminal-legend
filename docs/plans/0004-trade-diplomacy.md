# 贸易与外交最小闭环

- Status: proposed（排在经济循环之后）
- Depends on: `0003-economic-loop.md`、ADR 0001（月度会议/秘书）、ADR 0002（自由数值）、ADR 0003（引擎/LLM 边界）、ADR 0004（修正叠算）

## 已定决策

| 问题 | 决定 |
| --- | --- |
| 范围 | 贸易 + 外交最小闭环，含最小战争目标 |
| 贸易粒度 | 每国每商品 **Top-6** 伙伴 |
| 流量方向 | 进口需求缺口优先：本国需求先由国内产能满足，缺口从最有竞争力的伙伴进口 |
| 关税收入 | 用实际进口关税替换现有的抽象 `tradeVolume × 关税` 项 |
| 贸易→关系 | 基础是对称缓慢漂移；敏感商品由 agent 按交易物决定额外影响（如鸦片让中英关系恶化） |
| 资源进口 | 战争/禁运立即影响原料可得性；可用资源 = 本国禀赋 + 进口 |
| 外交局势 | 触发 → 各国提案（立场 + 效果条目）→ 仲裁 agent 从预置结果包中选择 → 引擎落账 |
| 月度调用 | AI 国家一次批量；玩家国由主模型/秘书单独处理 |
| 战争目标 | 赔款、开放市场、势力范围、威望羞辱（无省份，不做割地） |

## 1. 双边贸易

### 1.1 流量

对每国每商品：

1. 计算国内需求（来自 `0003` 的 C+I+G）。
2. 国内产能先满足需求；缺口为进口需求，盈余为可出口量。
3. 伙伴按竞争力排序：`价格差 × 关系 × (1 − 关税) × 交通/市场接入`，取前 6。
4. 进口国支付货款并征关税；出口国获得收入。
5. 贸易收支进入 GDP 的 NX；关税进入政府收入。

### 1.2 关系效应

- 基础：双边贸易占一国贸易的比重越高，关系每月向正向缓慢漂移（对称）。
- 敏感商品：每国 agent 在月度批量中可提交 `tradeTension`：
  ```ts
  { good: GoodId, partner: string, relationDelta: number, reason: string }
  ```
  引擎校验商品白名单（鸦片、军械、粮食等）、每月幅度信封与关系下限后落账。
- 战争、禁运、关系破裂立即切断相关流量。

## 2. 外交局势

沿用术语：事件树 / 局势 / 立场 / 提案 / 结果包。

```ts
Situation {
  id, title, triggers, participants,
  context(world): string,          // 引擎生成的历史上下文
  envelope: { stats, maxEffects, monthsRange },
  order: 'simultaneous' | 'sequential',
  outcomes: OutcomePackage[]       // 仲裁只能选一个
}
```

流程：

1. 触发条件满足 → 建立局势，写入 `world.situations`。
2. 向参与国征求提案（AI 批量 / 玩家侧单独）；提案 = 立场 + 效果条目。
3. 仲裁 agent 读取各方提案与局势上下文，从 `outcomes` 中选择一个结果包。
4. 引擎应用结果包内各参与国的确定性修正，写编年史，关闭局势。
5. 记录各方提案与仲裁选择，保证存档可复现；测试 mock 仲裁。

### 首个局势（已定）

**鸦片危机（QING / GBR）**。用户可见的未来都会扮演大清，因此贸易切片应侧重大清相关内容：
敏感商品、禁运、关税与关系恶化都优先围绕中英贸易设计。备选东方问题、德意志关税同盟留待后续。

## 3. 最小战争目标

宣战时声明一个目标；停战时按战争分数与目标决定条款：

| 目标 | 胜利效果 | 失败效果 |
| --- | --- | --- |
| 赔款 | 战败方国库支付赔款，债务上升 | 进攻方威望下降 |
| 开放市场 | 战败方关税下降、市场接入上升，限时修正 | 进攻方关系恶化 |
| 势力范围 | 战败方进入胜利方 `sphere` | 胜利方威望受损 |
| 威望羞辱 | 胜利方威望上升，战败方合法性/威望下降 | 进攻方合法性下降 |

## 4. UI
