## 0. 已定决策（grilling 结果）

| 问题 | 决定 |
| --- | --- |
| 科技树形态 | **工业、行政、军事 3 条分支 + 通用时代线**；其他旧科技并入通用线 |
| 规模 | **4 时代**：1836 / 1850 / 1865 / 1880；通用线 4 个时代节点 + 三分支各 4 个节点，共 **20 项** |
| 前置与互斥 | **分支内线性 + 时代门槛**；分支之间不互斥，选择只体现在先后顺序与点数分配 |

| 节点效果 | 第一版 **修正 + 少量法案/政策解锁**；新建筑/新商品（原备选 2）最终要做，先待定 |
| 国内跨分支溢出 | 当前研究点的 **15–25%** 流入另外两条分支的当前时代节点；比例取决于识字率、大学数量、教育支出与 buff |
| 国际科技扩散 | **研究速度加成**，按科技差距、贸易占比、关系、同盟计算，最高 **+50%**；不直接送点、不免费解锁 |
| 溢出驱动 | **贸易占比 + 关系 + 同盟**；不需要额外地理数据 |
| 世界版本 | **v7**；旧 v6 存档删除（ADR 0005） |

## 2. 研究机制

### 2.1 科技点产出

沿用现有公式：

```
pointsPerMonth =
  universities × 0.9 × (0.4 + literacy) ×
  (1 + education × 0.03) × (1 + era × 0.02)
```

- `techPoints` 修正仍然生效。
- 跨分支溢出与研究方向不改变点数总量，只改变流向。

### 2.2 选择节点

- 玩家/AI 选择一个**当前可研究**节点（前置满足、时代门槛满足）。
- 每月科技点流入该节点；完成后：
  1. 标记 `unlocked`；
  2. 应用该节点的永久修正；
  3. 记录编年史；
  4. `researching` 清空，等待下一次选择（AI 自动选下一项）。
- 未选择节点时，科技点不流失，暂存并显示“待选”。

### 2.3 国内跨分支溢出

- 当前研究点的 `15–25%` 同时流入另外两条分支的当前时代节点（平均分配）。
- 溢出比例：

```
spillRate = clamp(
  0.15 +
  literacy × 0.10 +
  min(universities / 20, 0.10) +
  education × 0.01,
  0.15, 0.25
)
```

- `techPoints` 类 buff 影响总点数，因此也影响溢出量。
- 溢出只推进**已解锁前置**的节点；未解锁分支不接收溢出。
- 溢出进度不触发“完成”以外的额外奖励；完成时正常应用修正。

### 2.4 国际科技扩散

- 对每国计算伙伴中最高的科技分：

```
techScore(c) = era × 10 + unlockedNodes.length
gap = max(partnerScore) - ownScore
tradeShare = 该国与先进伙伴的贸易额 / 该国总贸易额
bonus = clamp(
  gap × 0.02 +
  tradeShare × 0.20 +
  relation / 1000 +
  (alliance ? 0.10 : 0),
  0, 0.50
)
```

- 研究速度 = `pointsPerMonth × (1 + bonus)`。
- 只对“落后国”生效（`gap > 0`）；不直接送点、不免费解锁。
- 贸易/关系/同盟数据来自 0004；没有贸易时退化为只按 gap/关系。
- 战争/禁运期间该伙伴的扩散加成归零。

### 2.5 溢出与 AI

- AI 选择节点时考虑：
  - 领袖特质（工业/贸易 → 工业；军事/扩张 → 军事；改革/务实 → 行政）；
  - 当前国情（工厂少 → 工业；激进高/合法性低 → 行政；战争/军队弱 → 军事）；
  - 时代门槛（优先补通用线）。
- 确定性兜底：按权重排序，取最高；同权重按节点 id 字典序，保证可复现。

- 节点效果全部走 `addModifier`，`source: 'tech:<id>'`，永久。
- `unlocks` 只写标记（如 `electrification`），本切片不新增建筑/商品；后续切片读取标记。
- 研究完成不消耗权威；科技不是政策，不进政策维护费。

## 6. 测试与验收

1. **节点解锁**：前置/时代不满足时拒绝；满足后可研究；完成后修正生效。
2. **跨分支溢出**：主研究 15–25% 流入其他分支；识字率/大学/教育提高比例；上限 25%。
3. **国际扩散**：落后国获得最高 +50% 速度；贸易/关系/同盟提高；战争/禁运归零。
4. **AI 选择**：同种子同国情选同一节点；人格/国情改变选择。
5. **120 个月基线**：科技进度有限、不越时代、不出现负成本/NaN。
6. **存档**：v7 读取；旧 v6 拒绝（ADR 0005）。
7. **渲染**：科技页在 terminal/desktop 可绘制。
