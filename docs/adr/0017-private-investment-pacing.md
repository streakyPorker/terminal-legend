# 私人投资节奏：三月一单、最多三单在途

- Status: accepted（World v7，增量规则，不升版本）
- Fixes: PT-029

## 背景

1837–1838 年试玩中，私人部门最多同时挂着 **10 个**私人项目（每个 5 座矿场），
每月还在新增；私人队列比国有队列还长，看起来像“第二个国家”在建设。
原本的 `ownProjects.length < 10` 只是防止无限增长，没有节奏约束。

## 决定

```
MAX_PRIVATE_PROJECTS = 3        // 同时在途的私人项目
PRIVATE_START_INTERVAL = 2      // 两次开工之间至少隔 2 个月
```

- 扩张与更新（renewal）都受这两个限制；`econ.lastPrivateStartTick` 记录上次开工。
- 私人资本仍按储蓄积累，闲置部分继续释放为奢侈消费；只是不再一次性排满。
- 私人项目仍不可取消、自建 50%、可租国有闲置点。

## 代价

- 私人建设对需求的反应变慢；长期折旧的更新投资最长可能出现约 10 个月的空档
  （测试上限从 8 个月放宽到 10 个月）。
- 私人资本更容易积压成闲置利润，直到下一个开工窗口。
- 未来若引入“私人建造局”或投资信心机制，可再调这两个常数。
