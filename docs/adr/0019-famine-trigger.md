# 饥荒事件需要真实的粮食短缺

- Status: accepted（World v7，事件条件，不升版本）
- Fixes: PT-025

## 背景

1837.01 的饥荒事件在 **粮价 0.6**（基准 1.0，长期过剩且仍在出口）时触发。
旧条件是 `生活水平 < 45`，与粮食供需无关；玩家无法从价格或库存预判，观感突兀。

## 决定

饥荒事件的触发条件改为：

```
生活水平 < 45
且 粮价 ≥ 基准价 × 1.05
```

- 只有粮价高于基准（短缺信号）时才会闹饥荒；粮食过剩时不再抽到这张牌。
- 事件文本仍写“部分产粮区歉收”，保留局部灾害的解释空间。
- 赈济仍只扣国库，不消耗粮食库存；库存模型留给后续事件树（0002）。

## 代价

- 粮食长期过剩的国家几乎不会遇到饥荒，饥荒更多出现在战争、封锁或歉收年份。
- 粮价是唯一门槛，尚未区分“全国短缺”与“局部转运不畅”；后续可在 0002 里做区域化。
