# 进出口关税拆分：进口税率与出口税率可以不同

- Status: accepted（World v7，增量规则，不升版本）
- Amends: ADR 0009 的“进出口同税率”部分

## 背景

ADR 0009 用同一个 `tariff` 同时征收进口税与出口税。试玩到 1836.11 时，玩家要求
**“进口关税拉到 30%”**，同时仍要“粮食木材出口搞起来”。单税率做不到：把税率提到 30%，
大清自己的粮食、木材出口也会被 30% 的出口税打掉。

保护幼稚工业与鼓励原料出口是两种方向相反的政策，需要两个旋钮。

## 决定

### 1. 两个税率

```
econ.tariff        // 进口税，落在进入本国的货物上
econ.exportTariff  // 出口税，可选；缺省 = econ.tariff（旧行为）
```

- `exportTariff` 缺省时，进出口同率，ADR 0009 的旧存档与旧测试行为不变。
- 一旦显式设置，两个方向各按各的税率征收。
- 读取出口税一律走 `exportDutyRate(country) = exportTariff ?? tariff`。

### 2. 到岸价与征收

```
到岸价 = 出口国国内价 × (1 + 出口国出口税) × (1 + 进口国进口税)
        × 运输 × 接入 × 风险
```

- 出口税由出口国国库收取，进口税由进口国国库收取，互不替代。
- 进口税按“已经含出口税的边境价”计征（ADR 0009 不变）。
- 民怨压力仍按**进口税**计算（直接推高国内物价的是进口税）。

### 3. 操作与国策

- `v3_action tariff`：`rate` 设进口税率；可选 `exportRate` 单独设出口税率；
  省略 `exportRate` 时两者同率（并把 `exportTariff` 落成显式值）。
- 自由贸易 / 保护关税法案同时调整两个税率（各 −8 / +8）。
- 鸦片危机“妥协”结果同时下调两个税率。
- 状态、面板、AI 领袖提示与秘书简报都显示“进口 X% / 出口 Y%”。

## 代价

- 存档多一个可选字段；旧档缺省即同率，无需迁移。
- 玩家可以只保护进口、放开出口，贸易政策的空间变大，也更容易出现“进口税极高、
  出口税为零”的极端组合；后续可用行政能力或外交约束限制税率差。
- 单一税率仍是默认，不强迫所有国家分拆。
