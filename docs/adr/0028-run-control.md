# 托管运行的手动停止（v3_control / /v3 stop）

- Status: accepted（World v11，纯控制面，不升版本）
- Fixes: **PT-039**（托管启动后没有手动停止入口）
- Depends on: `docs/plans/0006-gm-engine-interface.md`、ADR 0001（御前会议与秘书）、ADR 0016（GM 明细接口）

## 背景

托管（`v3_advance { months: N }`，N > 1）会**立刻返回**「托管已开始」，随后在后台逐月推进。
引擎只在几种**自动**条件下打断（`councilInterrupt`）：遇待决事件、爆发新战争、战争结束、
秘书越权（`hooks/council.ts` 的 `interruptReason`）。

PT-039 记录了缺口：玩家开了一段 9 个月的托管后要求**停下**，GM 侧没有任何手段——
再调 `v3_advance { months: 1 }` 只得到「托管进行中，请等它结束」，其余 `v3_*` 工具都没有
托管控制参数。玩家一旦误开一段长托管，**只能等它跑完或被事件截住**；手动干预的
唯一窗口（御前会议）恰恰被托管关闭了。

## 决定

### 1. 新增 `v3_control` 工具

```ts
v3_control { action: 'stop' | 'save' }
```

- `action: 'stop'`：请求**打断正在进行的托管**；没有托管在跑时返回「当前没有正在进行的托管」。
- `action: 'save'`：写存档（等价 `v3_save` 的默认路径）。
- 该工具**只作用于玩家国家**、基本只读；不改变世界结构。

### 2. 停止是**协作式标志**，在当前月结束后生效

停止**不是**强杀后台任务，而是置一个**停止标志**，由运行循环在安全检查点轮询：

```
stopRequested = true                 // v3_control stop / /v3 stop 置位
runDelegated 循环:
  每个月开始前 → if (stopRequested) 以「手动停止」中断
  每个月推进后 → if (stopRequested) 以「手动停止」中断
```

即**当前月的推进一定会跑完**（不会中断一次月结算到一半），然后循环在下一次迭代前退出，
并把中断原因写进御前报告。这样保证世界状态始终是**整月一致**的（不会停在半结算态）。

- 标志位由 `hooks/internal.ts` 的 `requestDelegatedStop` / `isDelegatedStopRequested` /
  `clearDelegatedStop` 管理；`startDelegated` 在开局**清空**标志（避免上一局的残留标志
  误停新托管）。
- 停止后如仍有待决事件/战争，玩家照常在御前会议处理；停止**不跳过**任何结算。

### 3. `/v3 stop` 命令

命令层（`hooks/commands.ts`）新增 `/v3 stop`，与 `v3_control stop` 调用同一函数
`stopDelegated`，返回「已请求停止托管，将在本月推进结束后停下」并在 UI 弹一个提示。
托管启动文案（`startDelegated`）同时改为**主动提示**如何中断：
「…遇待决事件、战争或秘书越权会停下并提示，也可用 /v3 stop（或 v3_control stop）手动停止」。

### 4. 秘书**不获授权**，越权会被审计

`v3_control` **不加入 `SECRETARY_TOOLS`**——控制运行（尤其停托管）属于玩家主权，
秘书的授权范围是内政与（可选的）外交。若秘书仍通过其他路径调用，handler 里的
`auditOverreach($, '控制托管')` 会**记录越权**，并在连续越权达阈值时拒绝
（与 `v3_advance` 的「推进时间」审计同构）。

## 代价

- 停止**不是即时的**：若某月结算很慢，玩家要等这一月跑完。这是刻意的
  ——换来「世界永不停在半结算态」的一致性。
- 停止标志是**进程内**状态（`hooks/internal.ts` 的模块级布尔），不写存档；
  进程重启后无意义，托管本就不跨进程。
- 新增一个工具面，需要模型在托管期间知道它的存在；靠托管启动文案与手册 §2 双写提示。

## 暂不覆盖

- **暂停/恢复**：本 ADR 只做「停止」，不做可恢复的暂停（托管结束后玩家可重新开）。
- **步进托管**（按月等批准的人工节奏）：托管与逐月批准已是两种模式，不加第三种。
- **停止后自动处理待决事件**：停止只是回到御前会议，事件仍由玩家处理。

## 不变量（要求保持）

- 世界状态永远停在**整月边界**；停止**不产生**半结算状态。
- 停止必须在下一个安全点生效，且中断原因诚实记入御前报告（「手动停止」）。
- 除玩家外的调用者（秘书）触发 `v3_control` 一律**审计**。
