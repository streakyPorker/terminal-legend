# 科技基础研究率：没有大学也不至于停滞

- Status: accepted（World v7，增量规则，不升版本）
- Fixes: PT-007

## 背景

旧公式只有大学产出科技点：`大学 × 0.9 × (0.4 + 识字率) × …`。
没有大学的国家（例如开局的大清）每月只有约 0.3–0.6 点，升到 2 级要六十个月以上；
玩家看到「研究：农业改良」两年不动，会以为系统坏了。

## 决定

```
pointsPerMonth = base + universities × 0.9 × (0.4 + 识字率)
                        × (1 + 教育支出 × 0.03) × (1 + 科技等级 × 0.02)

base = 2 + 识字率 × 3 + 官僚效能 × 0.06
```

- 开局大清（识字 12%、官僚 30）约 **4 点/月**，2 级约需 35 个月；随识字与行政改善加速。
- 大学仍是主要放大器：每所约 +0.6–0.9 点/月，并继续吃识字与教育支出的乘数。
- 科技成本曲线（`TECHS`）不变。

## 代价

- 科技整体比旧版快，但仍以“年”为单位；工业时代的差距靠大学与识字拉开。
- 需要重新观察 60 个月基线的科技等级分布，若过快再调 `base` 系数。
