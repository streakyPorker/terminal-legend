# 债务压力：小幅负净资产照常建设，债务/GDP 越高 debuff 越重

- Status: accepted（World v7，派生规则，不升版本）

## 背景

World v7 把国库压成单一净资产后，`settleConstruction` 仍用 `Math.max(0, treasury)`
作为国有建设的现金上限。结果是：贸易缺口只要把净资产打到 −2.9，国有工程就**整月实付 0**，
但月报仍显示“净 +12.2”，玩家会以为工程在推进（试玩 PT-012）。

这个“零以下即停摆”的悬崖不符合债务经济的直觉：轻微负债是正常的逆周期融资，只有债务
累积到一定比例，才应该通过越来越重的 debuff 约束国家，而不是一刀切停摆。

## 决定

### 1. 国有建设可以赤字融资

- `settleConstruction` 的现金上限从 `max(0, treasury)` 改为
  `max(0, treasury − (−gdp × 3))`，即允许净资产为负，直到 3× GDP 的重组底线。
- 新建项目的检查同样从“国库必须 ≥ 首月成本”改为“不得越过 3× GDP 底线”。
- 私人建设仍只花 `privateCapital`，不占国债。
- 3× GDP 重组兜底保持不变：越线后降债到 1.5× GDP，并进入 12 个月重组窗口。

### 2. 债务压力是连续曲线

令 `ratio = debt / GDP`，`severity = clamp((ratio − 0.25) / 1.75, 0, 2)`：

| 债务/GDP | 标签 | 收入惩罚 | 建设速度 | 合法性目标 | 月息加成 |
| ---: | --- | ---: | ---: | ---: | ---: |
| < 25% | 无 | 0 | 0 | 0 | 0 |
| 25%–50% | 轻度 | 0–1.4% | 0–2.9% | 0–0.7 | 0–0.06% |
| 50%–100% | 中度 | 1.4%–4.3% | 2.9%–8.6% | 0.7–2.1 | 0.06%–0.17% |
| 100%–200% | 重度 | 4.3%–10% | 8.6%–20% | 2.1–5 | 0.17%–0.4% |
| ≥ 200% | 危重 | 10%–20% | 20%–40% | 5–10 | 0.4%–0.8% |

- **收入惩罚**：税入、关税、港口、赔款收入按 `1 − incomePenalty` 计。
- **建设速度**：国有项目效率再乘 `1 − constructionPenalty`。
- **合法性目标**：从目标值中减去 `legitimacyPenalty`，替换原先“债务 > GDP 直接 −10”的悬崖。
- **月息加成**：直接加进 `debtRate`，与战争、弱授权、低威望、激进、重组窗口同一口径。
- 所有数值由 `engine/fiscal.ts` 的 `debtPressure(country)` 派生，不写入存档、不升世界版本。

### 3. 可见性

- `v3_status` 新增“债务压力”一行：比例、标签、四项 debuff 数值。
- HUD 在债务压力 ≥ 25% 时显示“债务压力轻度/中度/重度/危重”。
- `FiscalLedger.debtPressure` 暴露同一结构，供面板、预测与测试使用。

## 理由

- **悬崖 → 斜坡**：轻微负债不改变建设行为，只有债务累积才逐步收紧，符合“先借钱发展、再为债务付代价”的循环。
- **可解释**：玩家能看到 `ratio` 与四项惩罚，知道为什么税入变少、工程变慢、合法性下滑。
- **保留兜底**：3× GDP 重组仍是硬上限，避免无限借债。

## 代价

- 基线（12% 税、无玩家操作）84 个月的国债会从约 920 升到约 1270，约 2× GDP；这是有意允许的，测试改为断言“低于 3× GDP 重组线”，而不是固定 1000。
- 高债务下收入惩罚会放大结构性赤字，债务可能继续上行；这是 debuff 的设计目的，玩家需要通过加税、削减支出或出口/进口替代来逆转。
- 债务压力不改变存档结构，World v7 旧档可直接继续。
