# 月度御前会议 + 子代理秘书

- Status: accepted

每月时钟暂停一次，玩家在御前会议中审阅月报、处理事件并批准秘书计划；秘书是一个拥有全量游戏工具、靠提示词约束的 LLM 子代理，可在玩家授权的领域（内政、外交谈判）内自动执行，军事与战争永远由玩家亲自决定。

原因：把“随时可操作的沙盒”改成有节奏的回合制，让每月的取舍成为玩法核心；子代理能直接读写游戏状态，省去为每种委托单独实现执行器的成本。

代价：子代理拿到 `v3_advance`、`v3_cheat`、宣战/停战等全量工具，只能靠提示词与事后审计阻止越权。越权时记录日志并 toast 提示，不拒绝调用；同一局连续 3 次越权后再改为运行时拒绝，或退回受限工具集 / “只读 + 计划”模式。

实现注记：命令钩子有 10 秒的自有时间预算，且**等待 `turn.complete` 的裸 Promise 计入预算**（`$` 调用在途不计）。因此 `/v3 secretary` 与 `/v3 run` 必须立即返回、在后台继续；否则命令会被宿主判为超时并当作没有实现。
