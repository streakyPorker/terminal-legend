# 进口逆差归私人部门：私人资本/私人外债，不记国家国债

- Status: accepted（World v7，字段语义调整，不升版本）

## 背景

ADR 0006 把国库压成单一净资产后，贸易逆差中私人部门无法融资的缺口被直接扣到
`treasury` 上，变成国家国债。试玩中出现了反直觉的一幕：

```
收入 38.7 − 支出 26.5 = 净 +12.2
但净资产从 0 → −2.9（贸易缺口 15.1）
```

玩家会问：“收大于支，为什么国家还在负债？”（PT-013）

从会计上看，进口账单是**私人部门**的对外支付，国库只应经手关税，不应替私人还进口钱。
把私人逆差记成国债既不符合直觉，也把私人部门的消费/投资选择变成了国家的债务。

## 决定

### 1. 私人资本可以为负

- `Country.econ.privateCapital` 保持原字段，但允许为负。
- `privateCapital ≥ 0`：私人资本，可用于私人建设、支付进口。
- `privateCapital < 0`：**私人外债**，绝对值就是私人部门欠外国债权人的金额。
- 不新增存档字段，不升 World 版本；旧 v7 存档的 `privateCapital` 只要非负，语义不变。

### 2. 贸易结算不再碰国库

- `settleTrade` 仍计算 `drawnFromCapital` / `debtIncrease` / `dropped`，用于展示与测试。
- 调用方只对私人账户记账：
  - `externalNet ≥ 0`：`privateCapital += externalNet`（出口盈余先补私人外债，再变成资本）。
  - `externalNet < 0`：`privateCapital -= drawnFromCapital + debtIncrease`；`dropped` 保持豁免。
- **`treasury` 不因贸易逆差变动**；关税仍按 `tariffRevenue` 计入国家收入。
- `lastTradeDebt` 改为“本月私人部门新增外债”，仅作展示；`FiscalLedger.tradeGap` 同样只展示。
- 净资产实际变动 = `income − expense`，不再减去贸易缺口。

### 3. 私人外债的后果

- 私人建设预算 = `max(0, privateCapital)`：私人外债未还清前，私人资本不能新建项目。
- 支付能力 = 出口收入 + `max(0, privateCapital)` + GDP×3%：负资本不再提供支付能力。
- 出口盈余与储蓄会先填平负的 `privateCapital`，再转为可投资资本。
- 重组窗口内的 `dropped` 上限仍保留，但只影响私人外债，不影响国家信用。

## 理由

- **会计边界清晰**：国库只对税收、关税、国有支出与国有建设负责；私人的进口由私人账户承担。
- **政策含义正确**：进口替代（建矿、建厂）现在直接改善私人资本，而不是替国家还债；出口创汇也先修复私人资产负债表。
- **不再制造“国家替私人买单”的错觉**：收入大于支出时，国库确实会增加。
- **无需版本升级**：`privateCapital` 字段已存在，只是允许负值；当前存档可继续。

## 代价

- 私人资本可能长期为负，私人建设会停摆；玩家需要通过出口、储蓄或减少进口来修复。
- 私人外债暂未单独计息（后续可在 E4 加入），目前只通过占用私人资本与抑制私人投资体现。
- 国家不再因私人逆差被动加债，贸易失衡的财政压力下降；这会让“重商主义/出口导向”的收益更直接。
- 面板与月报需要区分“私人外债”和“国家国债”，避免把两者混为一谈。
