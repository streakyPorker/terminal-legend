# 国库抽象为净资产：单一余额、双向利率与分期赔款

- Status: accepted（World v7）

## 决定

国库只保留一个带符号的余额 `Economy.treasury`，语义是**净资产**：

- `treasury > 0`：主权基金，按基金月息生息，利息计入收入。
- `treasury < 0`：国债，按国债月息付息，利息计入支出。
- 删除独立的 `Economy.debt` 与 `Economy.lastDebtRepayment`；`debt = max(0, -treasury)`。
- 贸易逆差中私人部门无法融资的缺口直接扣减净资产（`lastTradeDebt` 单独展示，不进入支出）。
- 月度不再有“赤字转债务、盈余还本”的两步账；余额本身随收入、支出、贸易缺口与赔款变动。

## 利率

月度利率都是纯函数，受以下因素影响：

```
国债利率 = clamp(0.004
  + 战争 0.002
  + 合法性低于 50 的部分 × 0.004
  + 威望低于 20 的部分 × 0.004
  + 激进 ≥ 50 时 0.002
  + 重组窗口 0.004,
  0.002, 0.02)

基金利率 = clamp(0.0015
  + 合法性/100 × 0.002
  + min(威望/100, 1) × 0.002
  + 市场接入 × 0.001
  − 战争 0.0005,
  0.0002, 0.006)
```

利差保证“借贵存便宜”。利息按月初余额计算，并随当月收支进入余额，形成复利。

## 战争赔款

胜方只声明**总额**与**最长分期月数**；败方自行决定一次付清多少、余款分几期：

- 一次性部分从败方净资产立即扣除并加到胜方。
- 余额按败方的承受力（`max(0.5, 月收入 × 0.15)`）摊成月供，最长不超过胜方声明的年限；
  若摊不完，月供取 `余额 / 最长月数`，超出承受力的部分让败方净资产转负（即国债）。
- 分期日程存放在 `WorldState.indemnities`；每月的月供计入付款方支出、收款方收入，
  双方净资产同步变动，金币守恒。
- 默认条款：总额 = 败方 GDP × 0.1，最长 60 个月；玩家作为胜方可在停战工具中覆盖。

## 理由

旧的“非负现金 + 独立债务”模型要求玩家同时理解净额、还本和债务余额，而且会出现
“国库为正却另有国债”的直觉冲突。单一净资产把资产负债表压成一个数：正数是基金，负数是
国债；利率负责表达信用差异，贸易缺口和赔款自然并入同一本账。

## 代价

- **破坏性变更**：世界版本升到 v7，旧 v6 存档直接拒绝（ADR 0005），需要 `/v3 new`。
- 不再有“用现金按 8% 还本”的自动去杠杆；债务只能靠正的主权基余额或重组窗口消化，
  长期结构性赤字会让净资产缓慢下沉，直到触发 3×GDP 的重组兜底。
- 种子国库改为旧 `treasury − debt` 的净值（大清 13、英国 12、法国 −2、奥斯曼 −7 等），
  开局就会出现负有国债的国家。
