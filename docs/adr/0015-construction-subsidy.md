# 建设补贴：把闲置的“建设支出”变成建造能力

- Status: accepted（World v7，增量规则，不升版本）
- Closes: PT-019（`spending.construction` 失效旋钮）

## 背景

ADR 0010 之后，国有建设由建造点与债务空间决定，`spending.construction` 不再参与结算，
但仍留在面板与 `v3_action spending` 里（PT-019）。玩家在 1837.01 要求
“国家出资补贴建造局，提升建造能力”——正是这个旋钮该做的事。

## 决定

### 1. 每级补贴换来建造点

```
capacity += spending.construction × 1.5 点/月
expense  += spending.construction × 0.45 金/月
```

- 补贴点加在营造所产出之后，再一起受**原料可得性**的比例约束：木、粮、铁不够时，
  补贴出来的产能也按同一比例打折。
- 没有营造所时补贴不产生建造力（补助要有承接的营造局）。
- 补贴点与营造所产点完全同质：可被国有队列使用，也可在闲置时按 0.3 金/点租给私人。

### 2. 财政

- 新增支出项「建设补贴」，进入 `ExpenseParts`、财政账本、状态行与面板。
- 每级 0.45 金，高于全部出租时的 0.3 金/点租金，避免“领补贴再转租”的套利。
- 与其他支出一样受 `expense` 修正影响。

### 3. 与既有规则的关系

- `spending.construction` 不再是“拨款上限”，而是**常设补贴等级**；国有项目的实际支出
  仍由建造点与每点 0.2 金决定（ADR 0012/0013）。
- 营造所仍是产能主体；补贴是放大器，等级 0 时不花一分钱。

## 代价

- 补贴是经常性开支，长期挂在高等级会持续挤压财政。
- 补贴点也吃原料，木材/粮食/铁紧张时收益递减。
- 面板上的旧名称“建设”改为“建设补贴”，旧存档无需迁移（数值原样解释为新语义）。
