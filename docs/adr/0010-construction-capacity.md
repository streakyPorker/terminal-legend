# 建造能力：营造所、资源投入、队列槽位与私人租用

- Status: accepted（World v7，增量字段，不升版本）；槽位上限与“满额 1 个月”由
  `0011-construction-slot-limits.md` 修订。

## 背景

旧模型的“建造能力”只有一条金本位预算：`spending.construction × 0.8`。它没有专门的
建筑，也不消耗木材、粮食等实物；队列按工期排序，玩家看不到“这个月到底有多少建造力、
每个槽位吃了多少”。试玩中月报只显示“国有建设 14.1 金”，没有建造能力的概念（PT-017）。

用户要求：

1. 有一类建筑，消耗木头、粮食等资源，产出**建造点**；
2. 建造队列显示建造能力；
3. 每个槽位消耗指定的建造点，按队列顺序往下排；
4. 私人建造不占用国有的营造所，和国有经济/队列分开；
5. 国有建造力有空闲时，可以租给私人，国家获得收入。

## 决定

### 1. 新建筑：营造所（`workshops`）

- 名称“营造所”，造价 3 金，工期 3 个月。
- 每座每月产出 **4 建造点**，受科技、交通、市场接入影响。
- 每座每月消耗：木材 1、粮食 0.6、铁 0.3（作为中间需求进入商品市场）。
- 实际产出按输入可得性缩放：`min(1, 可用木材/需求, 可用粮食/需求, 可用铁/需求)`；
  可用量 = 国内产量 + 上月进口。缺木材/粮食/铁，营造所就开不满。
- 初始数量：大清 12、英国 24、法国 16、普鲁士 10、俄国 8、奥地利 10、美国 8、
  日本 3、奥斯曼 4、西班牙 4。

### 2. 项目消耗建造点

每个项目每月需要：

```
capacityCost = CAPACITY_COST[building] × project.count
```

| 建筑 | 每座每月建造点 | 建筑 | 每座每月建造点 |
| --- | ---: | --- | ---: |
| 农场 | 0.5 | 港口 | 1.5 |
| 矿场 | 1 | 大学 | 2 |
| 工厂 | 2 | 兵营 | 1 |
| 铁路 | 4 | 官署 | 1 |
| 营造所 | 1.5 | | |

- 队列按**入队顺序**处理，不再按剩余工期排序。
- 国内项目先拿满自己的建造点；剩余建造点才会轮到后面的槽位。
- 只拿到部分建造点的槽位按比例推进，后面的槽位继续等。
- 金本位成本仍在：国有项目走建设拨款，私人项目走私人资本；建造点是速度闸门，
  金币是支付闸门，两者都不足时取较小者。

### 3. 国有与私人分开

- 国有项目优先使用国有营造所的建造点（严格队列顺序）。
- 私人项目有自己的组织能力，相当于每槽 50% 的建造点；不占用国有建造点。
- 国有建造点有闲置时，私人可以按 **0.3 金/点** 租用，租金从私人资本转入国库，
  记为“私人租用闲置建造力”。
- 私人项目即使租不到国有建造点，也能以 50% 速度推进；国有项目则完全受国有建造点约束。
- UI 分两栏：`国有建造队列`（显示建造点 a/b、已分配/闲置）与 `私人建造`
  （显示私人出资、进度，不占国有建造点）。

### 4. 数据与兼容

- `Economy.buildings.workshops` 为新增建筑计数。
- `Economy.lastConstructionRent` 记录本月私人租用收入。
- `ConstructionProject.lastCapacity` 记录本月分到的建造点。
- 世界版本仍为 v7；`parseWorld` 对旧 v7 存档做增量归一：
  - 缺少 `workshops` 时，按 `min(24, max(1, round(factories / 2)))` 补；
  - `lastConstructionRent`、`lastCapacity` 缺省为 0。
- 不新增建筑槽位以外的持久结构，不触发旧档拒绝。

## 理由

- **实物约束**：木材、粮食、铁真的进入商品市场，营造所不是凭空产生建造力。
- **队列可读**：玩家能看到“本月 40 点，国有需求 56 点，已分配 40 点，闲置 0”，
  以及每个槽位吃多少点。
- **国有优先、私人租用**：既保证国家工程优先，又让闲置产能产生现金流。
- **兼容当前局**：旧档自动补营造所，不必重开。

## 代价

- 建造速度不再只由金币决定；缺木材/粮食/铁会拖慢工程，需要玩家补农场、矿场或进口。
- 私人建造速度默认只有 50%，除非国有产能闲置；这会让私人资本更依赖国家营造所。
- 数值（4 点/座、0.3 金/点、50% 私人自有）是第一版校准，后续可按 24 个月基线调整。
