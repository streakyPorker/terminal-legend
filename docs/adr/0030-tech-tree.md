# 科技树：通用时代线 + 三分支（tech tree）

- Status: accepted（World **v13**：4 时代 / 16 节点科技树取代 1–10 级线性科技）
- Fixes: 线性科技「每级同价、看不出选择」的问题——玩家/ AI 需要的是**方向**（工业 / 行政 / 军事）与**时代门槛**，而不是一条自动爬的等级条（plan 0005 §0）
- Depends on: `docs/plans/0005-tech-tree.md`、ADR 0004（修正叠算）、ADR 0005（不做存档兼容）、ADR 0018（研究基础率）、ADR 0024（配置分层与修正块）
- Supersedes: 「1–10 级线性 `Technology.level`」模型

## 背景

旧科技是一条 1–10 级的线性等级：每月科技点自动涨，到阈值自动升一级，每级同价、无分支、无选择。
plan 0005 §0 的诊断是：**没有可做的决策**——玩家无法把有限的研究点导向「先工业化」还是「先扩军」，
AI 也没有可解释的偏好，UI 只能显示一个进度条。经济（plan 0003）与贸易（plan 0004）已经能给出
「工厂少 / 激进高 / 在打仗」这些可读的国情信号，科技却没有消费它们的接口。

## 决定

### 1. 树形态：通用时代线 + 工业 / 行政 / 军事三分支（World v13）

- **16 节点**：通用线 4（`general-1836/1850/1865/1880`，逐级解锁**时代 I–IV**）+ 工业 / 行政 / 军事
  各 4 节点（`industry-*`/`admin-*`/`military-*`）。
- **`era 1..4` 是层级（Tier I–IV），不是日历年**。节点可带可选 `year`（自 1836 起的年偏移）作为历史
  节奏的软提示，不硬卡。
- **门槛**：分支内线性前置 + 时代门槛（分支节点要求 `era ≥ node.era`）；通用线节点自身是** raise era
  的那一步**，因此只受前置与 `requiresAnyBranch`（`general-1865` 需任一分支 2 项、`general-1880` 需 3 项）约束。
- **分支之间不互斥**：选择只体现在先后顺序与点数分配（plan 0005 §0）。

### 2. `techTier` 连续代理

删除 `tech.level` 会打断 6+ 处受科技门控的公式（生产、威望、sol、城市化、战争强度）。
新增派生值：

```
techTier = 1 + era × 1.5 + unlocked.length × 0.05     // 范围约 2.5–7.8
```

旧公式一律改读 `techTier`（或 `tech.era`、`tech.unlocked`），`1 + tier × 0.07` 门控曲线**不变**，
这样树替换不会改变既有平衡。`techTier` 是**纯派生**值，不落存档。

### 3. 数据模型与效果

```ts
export type TechState = {
  era: number                       // 1..4
  nodes: Record<string, number>     // node id -> 0..1 进度
  unlocked: string[]                // 已解锁节点 id
  researching: string               // 当前节点 id，或 ''（待选）
  points: number
  pointsPerMonth: number
}
```

- 节点表 `TECH_NODES` 表驱动（`id/era/branch/name/cost/prerequisites/effects/unlocks?/year?`），
  **节点造价单一真源**在 `TECH_ERA_COSTS`（config），由 `techNodeCost(era)` 派生。
- 效果两类：**永久/限时修正**走 `addModifier({source:'tech:<id>'})`；**一次性**（`legitimacy`/`loyalists`/
  `radicals`/`morale`）在完成时直接改一次存量并 clamp（ADR 0004：flat 存量不进永久流量）。
- `unlocks`（如 `electrification`）只记录标记，供后续建筑/商品切片读取；本切片不新增建筑/商品。
- 新增 `navyStrength` 修正入口（与 `armyStrength` 并列），不新增公式特判。
- 修正上限由 64 提到 **128**，避免早期永久科技被限时修正静默挤掉。

### 4. 研究机制

- **月产出**沿用旧公式：`universities × 0.9 × (0.4 + literacy) × (1 + education×0.03) × (1 + era×0.02)`，
  外加基础率（ADR 0018）与 `techPoints` 修正。
- **跨分支溢出**（K2）：主节点拿全额，额外 `15–25%` 平均流入另外两条分支的当前时代节点；比例随识字率 /
  大学数 / 教育支出上升并 clamp 到 `[0.15, 0.25]`。溢出是**额外进度**，不扣主节点。
- **国际扩散**（K2）：落后国按 `gap×0.02 + 贸易占比×0.20 + 关系/1000 + 同盟×0.10` 得到研究**速度**加成，
  上限 **+50%**；与先进伙伴战争 / 禁运时归零。不送点、不免费解锁。
- **AI 选择**（K3）：非玩家国每月确定性选下一个可研究节点——分支权重由**时代门槛优先**（优先补通用线）+
  **领袖特质**（工业/贸易→工业；军事/扩张→军事；改革/务实→行政）+ **国情**（工厂少→工业；激进高/合法性低→
  行政；战争/军队弱→军事）叠加，**同权重按节点 id 字典序**兜底。**不引入 RNG**，同种子 + 同国情 ⇒ 同选择。
- **研究切换**只经 `v3_action research tech=<节点 id>` 或科技面板的 `research` 控制；面板**不直接写状态**。

### 5. K4 调平

- 节点造价翻倍（初稿 80/180/360/640 → 定稿 **160/360/720/1280**），只动 `TECH_ERA_COSTS` 这一个 dial。
- 120 个月基线（玩家国）约 **+3 节点 / 10 年 ≈ 每 2–4 年一节点**；进度有限、单调、`era ≤ 4`、
  无负成本 / NaN。回归测试锁定节奏、有界与 120 个月确定性。

### 6. UI

- 科技页（既有「科技」页签，**不新增页签**）：顶部时代 / 科技点/月 / 当前研究 / 溢出比例 / 国际扩散加成；
  其后通用线一行，工业 / 行政 / 军事三列；每个节点显示名称、时代、造价、进度条、效果、前置与状态
  （可研究 / 进行中 / 已解锁 / 锁定）。窄终端降级为单列列表。

## 后果

- 玩家与 AI 都能把研究点导向一个**可解释的方向**；AI 选择可复现，便于测试与回放。
- `techTier` 保持了旧公式的连续性，树的引入不改变既有经济/军事平衡曲线。
- 造价集中在一个配置数组，节奏可单点校准；K4 的翻倍只改一个常量。
- 旧 v12 存档按 ADR 0005 拒绝（`unlocked` 语义由「等级」变为「节点 id」）。
