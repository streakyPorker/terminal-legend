# 早期开发不做存档兼容

- Status: accepted

在当前阶段，世界结构变化时直接提升 `WorldState.version` 并拒绝旧版本存档；不写
`migrateWorld`，不为旧字段保留兼容分支，旧存档可以直接删除。

原因：第一刀期间数据模型仍在快速变化（基础设施拆分、官僚、建造队列、修正层），
迁移代码的维护成本高于重开一局的成本；兼容层还会把过时字段带进新公式，掩盖真正的
设计问题。

代价：每次破坏性改动都会让当前存档失效。需要重开时用 `/v3 new`；`parseWorld` 只接受
当前版本，读到旧存档会当作“没有存档”。等 Slice C 结束、结构稳定后再讨论迁移。
