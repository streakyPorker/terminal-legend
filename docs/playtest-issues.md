### PT-001 全球粮食过剩，农产品没有世界市场

- 日期：2026-10-20
- 世界：1836.01–1836.02
- 存档：seed=9100 / 玩家=QING（24 个月无玩家操作基线）
- 现象：大清粮食、木材、成衣都大量过剩，但 24 个月里出口始终为 0。
- 数据：24 个月基线中，粮食每月都是 10 国全部 offer、0 个 bid；大清第 1 月粮食产量 2692、需求 195（13.8 倍）；十国粮食生产/需求比在 6.96–24.77 之间。
- 判断：不是价格或关系问题，而是**全球农产品结构性过剩**。贸易清算只匹配“有 bid 的进口国”，所以大清永远卖不出去。根因是农场系数（1.05/月/座）相对 Stone-Geary 粮食需求过高。
- 修复：32e624b（E1 第一轮）把农场粮食系数降到 0.30、农场木材降到 0.04、矿场木材降到 0.04，并让工厂消费粮食（×1.0）制造工业国需求。24 个月基线：粮食 bid 24/24、大清粮食或木材出口 24/24。
- 关联：0007-E1
- 状态：fixed（32e624b）

### PT-002 成衣/酒/家具/军械同样全球过剩

- 日期：2026-10-20
- 世界：1836.01–1836.02
- 存档：seed=9100 / 玩家=QING
- 现象：除粮食外，成衣、酒、家具、军械也全部是 offer、没有 bid。
- 数据：24 个月中，clothes/liquor/furniture/arms 的 bid 月份均为 0，offer 月份均为 24；十国生产/需求比：成衣 2.3–11.4、酒 1.4–7.3、家具 1.5–12.6、军械 1.1–5.5。
- 判断：消费品与军工也系统性过剩；全球贸易只剩煤/铁/布/木材/鸦片等少数商品，分工不成立。
- 备注：32e624b 的 E1 第一轮只修了粮食/木材/机械；成衣、酒、家具、军械仍是全球 0 bid。留待第二轮决定是下调产出系数，还是承认这些商品以本地自给为主。
- 修复（B5，2026-10-21 本会话，plan 0008 §5）：采用「**本地自给**」这一允许路径。B5 曾试验砍掉手工匠
  （`ARTISAN_OUTPUT`）供给，成衣/酒/家具确会变成真双向（每 12 月两侧都有），但代价是农村实际收入
  崩落、并**饿死 QING→GBR 鸦片贸易**（鸦片危机门 ≥2 单位/月 跌到 0.85）——而鸦片门是结构不变量。
  最终保留手工匠供给（`ARTISAN_OUTPUT` 原值 0.035/0.01/0.006），在 `engine/data.ts` 与 ADR 0021 明确
  注释：这三种消费品以本地手工匠自给为主，不做全球双向贸易。军械同理（本地军供）。判断依据：
  plan §5 的 gate 原文允许「真双向 **或** 明确判为本地」。
- 关联：0007-E1、0008 B5、0008 B5-r2
- 状态：**fixed（B5-r2，2026-10-21，commit dcdb559，plan 0008 §5）**——成衣/酒/家具转为**真双向**全球贸易，军械**显式记录**
  为唯一非双向商品（有生产下限断言）。B5 的「本地自给」判定被用户决议推翻。
- F7 复核（2026-10-21，plan 0011 §7.8）：B5 阶段消费品按设计本地自给；该历史结论已被 B5-r2 取代（见下）。
- 修复（B5-r2，2026-10-21，plan 0008 §5）：B5 的「本地自给」使 PT-002 只**声明**收敛、未真正双向。用户决议
  消费品应**全球可交易**，故 B5-r2 从**工厂侧**造 bid，不动手工匠（`ARTISAN_OUTPUT` 原值），避免 B5 砍手工匠
  时「农村实际收入崩落 → 饿死鸦片门（≥2 跌到 0.85）」的老路。三处数值：
  1. `textileMills.output` `{fabric 1.45, clothes 0.68}` → `{fabric 2.0, clothes 0.2}`：工厂转做布料（中间品），
     成衣交给手工匠；布料增产保住纺织厂增加值与工业毛利带。
  2. `furnitureWorks` / `distilleries` **整条配方（产出 × 投入同乘 0.45）**：`furniture 1.54→0.693`、
     `liquor 1.9→0.855`；产出与投入同缩 → **每座经营毛利不变**，而供给降到足以让他国出 bid。
  3. 消费品需求侧：`SUBSISTENCE` 成衣 `1.2→1.5`、酒类 `0.6→5/6`、家具 `0.3→5/12`（×`SUBSISTENCE_SCALE`）；
     `INCOME_ELASTICITY` 成衣 `0.18→0.25`、服务 `0.27→0.2`（份额和仍 =1）。
  **实测（seed 9100，84 月基线）**：成衣 **81/84** 月双侧（缺第 1–3 月，其后每 12 月窗口 ≥9 月）、酒类 **84/84**、
  家具 **81/84**；军械 0 bid（保留：强推会越过 F7 农业/采掘毛利上界，故文档化为非双向）。**鸦片门保持**：QING 鸦片进口
  最小 2.251（≥2，较基线 2.226 略升）、GBR 份额最小 0.584（≥0.2）、关系最小 −43.4（> −50）。工业聚合毛利
  16.6% / 14.4% / 12.3%（24/48/84 月，带内）；F7 各族毛利带全通过；World 仍 v11（纯数值）。gate 已收紧：
  `tests/economy-recipe-calibration.test.ts` 把成衣/酒/家具并入「每 12 月双侧」窗口断言。

### PT-003 机械全球短缺，没有任何 offer

- 日期：2026-10-20
- 世界：1836.01–1836.02
- 存档：seed=9100 / 玩家=QING
- 现象：机械 24 个月全部是 bid、0 个 offer，任何国家都买不到机械。
- 数据：十国机械生产/需求比 0.37–0.88；最后的全球 bid 合计 34.3、offer 0。
- 判断：工厂机械产出（0.09/座/月）低于需求（每座工厂 0.18 + 建设需求），所有国家都短缺；机械无法通过贸易获得，只能自建工厂，贸易层少了一条重要链路。
- 修复：32e624b（E1 第一轮）把工厂机械产出翻倍到 0.18/座/月；24 个月基线机械 bid/offer 均为 24/24，英法普澳美可向大清等低技术国出口。
- 关联：0007-E1
- 状态：fixed（32e624b）

### PT-004 贸易缺口转外债，净资产 13→0

- 日期：2026-10-20
- 世界：1836.02
- 存档：实际存档（玩家已执行税 20/建设 18）
- 现象：首月账面净额 +3.0 金，净资产却从 13 掉到 0。
- 数据：进口 16.0 金、出口 0；贸易缺口 16.0 单独扣减净资产；进口构成：煤 7.9、布 4.7、奢侈品 1.4、鸦片 1.2、铁 0.8 等。
- 判断：支付能力 = 出口收入 + 私人资本 + GDP×3% ≈ 15 金；出口为零时，进口几乎全部转为外债。机制本身可解释，但玩家看不到支付能力与缺口分解，体验上像“钱凭空消失”。
- 修复：ADR 0008 把私人进口逆差归入私人资本/私人外债，不再扣国库；`v3_inspect fiscal/trade`（ADR 0016）现在逐项列出逆差、私人外债与进口货值。
- 关联：0007-E2、0006、ADR 0008
- 状态：fixed（ADR 0008、ADR 0016）

### PT-005 建造队列按工期排序，铁路长期 0%

- 日期：2026-10-20
- 世界：1836.02
- 存档：实际存档
- 现象：同一批项目里，矿场 65%、官署 52%、铁路 0%；铁路长期拿不到拨款。
- 数据：`settleConstruction` 按 `monthsLeft` 升序拨款；现金紧张时短工期项目先吃满预算，8 个月工期的铁路只能分到零头。
- 判断：玩家无法表达优先级，长工期项目会被静默饿死；应改为入队顺序、比例分配或最低保留拨款，并在面板显示“本月实拨”。
- 修复：ADR 0012/0013 改为按入队顺序分配建造点、每槽显示本月实投与预计回合，不再有“按工期排序”的饿死。
- 关联：0007-E3、ADR 0013
- 状态：fixed（ADR 0013）

### PT-006 首月 I=0，GDP 与建设支出对不上

- 日期：2026-10-20
- 世界：1836.02
- 存档：实际存档
- 现象：已经支付了建设款，GDP 构成里的投资 I 仍是 0。
- 数据：首月 GDP 503，C=508、I=0、G=14.4；建设实付 5.7 金。
- 判断：投资需求读取“上月实际建设支出”，所以首月必然为 0；这是有意的防“幽灵投资”设计，但状态与面板没有说明这个滞后。

- 关联：0007-E4、ADR 0016
- 状态：fixed（ADR 0016，口径可见）

### PT-008 失业率与原始劳动利用率口径打架

- 日期：2026-10-20
- 世界：1836.02
- 存档：实际存档 / 基线
- 现象：状态显示失业 7.5%–28.7%，同时“劳动原始利用率”只有 3.8%。

- 判断：两个指标名称相近但含义不同（工业就业缺口 vs 劳动需求占比），玩家无法判断哪个是真的失业；需要统一口径或改名。

- 关联：0007-E5、ADR 0016
- 状态：fixed（ADR 0016，口径可见）
